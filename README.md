# Rubi · Demo

Front da demonstração do SDR com IA.

Site: https://leonardorr.github.io/rubi-demo/

- `index.html`: demonstração guiada em 11 capítulos (capa, problema, atendimento, ficha, agenda, funil, assistente, controle, integrações, resultados e próximos passos). No capítulo 3 a Rubi responde de verdade.
- `simulador.html`: simulador em que o visitante descreve o próprio negócio e conversa com a Rubi.

Navegação da guiada: `→`/espaço avança, `←` volta, `P` abre o painel da apresentadora, `H` esconde os controles. O nome do cliente vai na capa ou em `?empresa=Nome`. O link `#3.2` abre direto no capítulo 3, passo 2.

A IA responde pelo backend publicado no Railway (repositório OliveiraIA). Ele só aceita chamadas vindas de `https://leonardorr.github.io`. Use dados fictícios: o encaminhamento comercial é simulado. Credenciais, conversas e código do backend não fazem parte deste repositório.
